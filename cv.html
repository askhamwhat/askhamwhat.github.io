Software

Maintainer

  • chunkIE Pedagogical and prototyping code for solving integral equations on curves. Chunk-based discretization with adaptive refinement and high-order quadrature. MATLAB toolbox for boundary integral equations on curves, available under the 3-clause BSD license.
  • optdmd Computing the optimized dynamic mode decomposition. MATLAB package, available under the MIT license.
  • RobustDMD.jl Fitting exponential functions to data with robust penalties. Julia package, available under the MIT license.
  • mbh2dfmm Stable fast sums of the modified biharmonic Green's function and modified Stokes kernels. Fortran package, available under the modified FreeBSD license.

Contributor

  • FMM3D Flatiron Institute fast multipole libraries, for fast particle sums. Contributed new kernels and Julia wrappers. Fortran library with MATLAB and Python interfaces, available under the 3-clause BSD license.
  • fmm3dbie Integral equation methods in three dimensions. Contributed Stokes codes. Fortran library with MATLAB and Python interfaces, available under the 3-clause BSD license.
  • fmm2d Fast particle sums in two dimensions. Contributed new kernels. Fortran library with high-level language wrappers, available under the 3-clause BSD license.
  • inverse-obstacle-scattering2d Inverse obstacle scattering in two dimensions. Contributed new options for the optimization routines and methods for impedance models. MATLAB package.
